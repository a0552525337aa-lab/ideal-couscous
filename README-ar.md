# موقع موجة — ملفات جاهزة للاستضافة

المشروع صفحة ثابتة واحدة: `index.html` (التنسيق والبرمجة مضمّنان داخلها). لا يحتاج إلى build أو تثبيت حزم.

## أسرع رفع: Vercel Drop

1. افتح [vercel.com/drop](https://vercel.com/drop).
2. اسحب ملف `mawja-static-site.zip` إلى الصفحة.
3. انسخ رابط الموقع بعد انتهاء الرفع.
4. النشر بدون حساب مناسب للتجربة لكنه مؤقت؛ أنشئ حساباً مجانياً واضغط **Claim Project** قبل انتهاء مدة النشر حتى يبقى الموقع. الرفع المباشر لا يرتبط بـ Git ولا ينشر التحديثات تلقائياً.

## رفعه على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع `index.html` إلى جذر المستودع، ويمكنك أيضاً رفع هذا الملف و`.nojekyll`.
3. افتح **Settings → Pages**.
4. من **Build and deployment** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/(root)`، واضغط **Save**.
5. بعد اكتمال النشر افتح رابط الموقع الظاهر في صفحة Pages. قد يستغرق ظهور التحديثات دقائق قليلة.

## رفعه على Vercel

1. ارفع ملفات المجلد إلى مستودع GitHub.
2. في Vercel اختر **Add New → Project** ثم اربط المستودع.
3. اختر **Other** كإطار العمل، واترك أمر البناء فارغاً؛ هذا موقع HTML ثابت.
4. انشر المشروع. وجود `index.html` في الجذر يجعلها الصفحة الرئيسية.

## ربط بث YouTube

من الموقع افتح **لوحة المشرف**، ثم أدخل رابط بث YouTube أو معرّف الفيديو، فعّل حالة البث، واحفظ. يمكن أيضاً تعديل الإعداد الافتراضي داخل JavaScript في `index.html` ضمن كائن `defaults` قرب بداية السكربت.

المشغل الحالي يستخدم YouTube embed، والدردشة تستخدم YouTube Live Chat. يجب أن يكون البث متاحاً للتضمين. رابط M3U8 غير مدعوم في النسخة الحالية؛ يحتاج مشغل HLS منفصلاً.

## ملاحظات مهمة قبل الاستخدام العام

- إعدادات لوحة المشرف في هذه النسخة تحفظ في `localStorage` على متصفح الجهاز فقط؛ لا تنتقل تلقائياً إلى زوار الموقع.
- لا يوجد تسجيل دخول فعلي للمشرف أو قاعدة بيانات مشتركة. لا تضع كلمات مرور أو أسراراً في JavaScript.
- لمشاركة رابط البث والجدول مع جميع الزوار، اربط إعدادات الموقع بخادم وقاعدة بيانات، وأضف تسجيل دخول وصلاحيات للمشرف.
- يلزم تقديم الموقع عبر HTTPS/localhost لعمل تضمين YouTube بصورة موثوقة، كما يجب أن يسمح YouTube بالتضمين لذلك البث.

## فحص محلي سريع

يمكن تشغيل مجلد المشروع بخادم ملفات محلي، أو رفعه إلى GitHub Pages/Vercel وفتح الرابط الناتج. اختبر الصفحة على الهاتف والحاسوب، ثم أضف بثاً عاماً قابلاً للتضمين من لوحة المشرف.
